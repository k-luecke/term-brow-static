This website uses the exact layout geometry and local curation model of TermBrow, an open-source Python / Textual terminal browser built for distraction-free technical reading. Press / (or Ctrl+K) to focus the command/search bar above, Alt+E to cycle Focus (15%) / Balanced (40%) / Discover (65%) exploration budgets, or run :keywords, :library, :history, and :help directly in the toolbar. Every state vector stays in your browser's local storage.
