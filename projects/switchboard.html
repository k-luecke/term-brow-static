Switchboard

A zero-dependency, single-file offline visual countdown timer and RFC 5545 (.ics) calendar import/export utility.

v1.0.0ZERO NETWORK CALLS

Design constraint

Schedule and focus tools rarely need an account, build step, or telemetry endpoint. Switchboard packs multi-timer visual state and standard .ics calendar interoperability into one self-contained local HTML/JS artifact.

Capabilities & limits

Runs locally from disk or static hosting with zero external network requests, local storage persistence, and clean RFC 5545 event parsing/export. Intentionally omits cloud sync and multi-user collaboration.
