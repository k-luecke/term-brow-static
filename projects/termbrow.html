TermBrow

A clickable terminal browser built around reading, research, source diversity, and low visual context switching.

WORKING

Interface

Pages are reduced to a stable reading column. Navigation, tabs, history, saved articles, search, and a discovery feed stay within the same visual context.

Discovery

The feed uses an explicit explore/exploit dial rather than silently optimizing for engagement. Discovery is budgeted and anchored near existing interests, with source-diversity caps.

Retrieval

Direct article extraction is preferred. The browser can fall back through alternate fetch strategies and static archived versions when normal reads fail.

Local state

Reading history, topic weights, library, and preferences stay in inspectable local files rather than a remote profile.

This site

The portfolio borrows the same design constraint: stable layout, restrained chrome, minimal animation, and a reading-first hierarchy. GitHub remains the source layer underneath it.
