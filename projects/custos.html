Open-source ESP32/ESP32-S3 SX1262 LoRa authenticated telemetry firmware, 24-bit I2S narrowband Goertzel DSP monitor, and a zero-cloud Python 3 SQLite TDOA & hash-chained incident vault.

v0.1.0AEAD + TDOA VERIFIED

Problem

Low-power sub-GHz sensor meshes frequently trade away packet authenticity, replay resistance, or local auditability in favor of proprietary cloud gateways.

Firmware & DSP

PlatformIO C++ firmware for ESP32 / SX1262 915 MHz LoRa nodes encrypts and authenticates 40-byte telemetry frames with RFC 7539 ChaCha20-Poly1305 AEAD and monotonic replay counters, paired with a 24-bit PCM1808 I2S acoustic/vibration monitor implementing sliding narrowband Goertzel tone detection.

Vault & TDOA solver

A dependency-light Python 3 receiver logs verified frames into SQLite, performs asymmetric Huber-loss time-difference-of-arrival (TDOA) localization across multi-node timestamps, and links every event into a SHA-256 hash chain.

Verification & limits

Includes an offline pytest suite covering RFC 7539 AEAD vectors, anti-replay rejection, TDOA geometry convergence, and hash-chain tamper detection. Published as generic reference firmware and local fusion code — hardware radio calibration, enclosure design, and site-specific RF link budgets remain user-supplied.
